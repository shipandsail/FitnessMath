# FitnessMath

Header-only fitness and nutrition formulas for Arduino and DIY trackers:

- `bmr()` Mifflin-St Jeor (1990) resting energy
- `tdee()` BMR x activity factor
- `metCalories()` calories burned from MET values (2024 Adult Compendium of Physical Activities), with constants for walking, running and cycling
- `macroCalories()` Atwater 4/4/9/7 kcal per gram
- `bmi()`, `proteinRdaG()`

See `examples/Basic`. Estimates for general wellness, not medical advice.

Web calculators with the same formulas: https://snowbelly.app/tools/calorie-calculator/
